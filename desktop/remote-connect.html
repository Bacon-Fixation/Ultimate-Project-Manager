Remote UPM Connections

Open another UPM dashboard on your LAN inside an isolated desktop window. Login credentials are entered into that remote UPM and are never saved in this connection list.

Add or edit a connection

Plain HTTP does not encrypt the UPM username/password or session cookie on the network. HTTPS is recommended even on a trusted LAN.

Saved connections

Each saved remote UPM gets its own isolated Electron browser session.

The remote UPM host must listen on a LAN-accessible interface and enable Remote Dashboard access. Remote actions and filesystem access remain controlled by that host's UPM security settings.
