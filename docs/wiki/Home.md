# Ultimate Project Manager Wiki

Ultimate Project Manager (UPM) is a local-first Electron and browser dashboard for managing multiple development projects from one place.

UPM combines project registration, verified backups, optional mirrored backup destinations, recovery, PM2 monitoring/controls, Docker readiness, service health, dependency inspection, project tasks, File Tools, Text Sanitizer, host telemetry, and LAN Remote Agents.

## Recommended first-time path

1. Install and start UPM.
2. Add one project.
3. Configure a primary backup location.
4. Create and verify a baseline backup.
5. Test browsing the backup history and recovery workflow.
6. Add PM2, Docker gating, service checks, encryption, schedules, or Remote Agents only where needed.
