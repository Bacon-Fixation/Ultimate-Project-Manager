# GitHub Wiki Source

This folder is the source copy for the Ultimate Project Manager GitHub Wiki.

GitHub stores a repository Wiki separately from the normal project tree. Keeping the pages here makes them reviewable, versioned, and easy to copy or synchronize into the Wiki when the public repository is enabled.
