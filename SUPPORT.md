# Ultimate Project Manager Support

## Start here

For normal setup and usage questions, check:

1. The built-in **Help** tab.
2. The project README.
3. The GitHub Wiki pages in `docs/wiki/` / the repository Wiki.
4. Existing GitHub issues.

Repository: https://github.com/Bacon-Fixation/Ultimate-Project-Manager

## Reporting a problem

Use the bug report template and include:

- UPM version
- Electron desktop or browser/dashboard mode
- operating system
- steps to reproduce
- expected and actual behavior
- the smallest useful log/diagnostic excerpt

Do not post `.env` files, authentication secrets, session keys, encryption keys, credentials, or private project contents.

## Feature requests

Use the feature request template and explain the workflow you are trying to improve. For backup, restore, process-control, remote-agent, or security changes, include how you expect safe failure and backward compatibility to work.
